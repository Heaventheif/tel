MEDIA BOT API

دليل التكامل المباشر

تدفق التكامل بسيط: افحص الرابط للحصول على الجودات، ثم أرسل الرابط ومفتاح الجودة إلى مسار التنزيل. لا تحتاج إلى مفتاح API أو ترويسة Authorization.

الواجهة مفتوحة عمداً. للحفاظ على الاستقرار، تطبق الخدمة قيود حجم جسم الطلب، والتحقق من الرابط، وحدوداً للمعدل، وقفل تنزيل مشتركاً مع بوت تيليجرام. استخدم رمز الحالة 429 وRetry-After لإعادة المحاولة بأدب.

تدفق العمل

1. POST /api/probe { "url": "https://…" } 2. اختر options[n].key من الاستجابة 3. POST /api/download { "url": "https://…", "key": "…" } 4. اقرأ stream الثنائي واحفظه كملف

لا تمرر حقلاً باسم extra. الخادم يعيد تنفيذ الفحص داخلياً ويستخدم بيانات المزود الموثوقة، حتى لا تُكشف روابط موقعة أو بيانات مؤقتة للعميل.

المسارات

GET/health

فحص سريع لحياة الخدمة، مناسب للمراقبة والاستضافة.

{ "status": "healthy", "ts": 1735000000.12 }

GET/api/health

حالة تشغيل تفصيلية مناسبة لفحوص Render والمراقبة العامة. لا تتطلب مصادقة.

{ "ok": true, "uptime": 3600, "plugins": 11, "activeDownloads": 1, "memoryMB": 128, "version": "2.0.0" }

GET/api/plugins

يعيد الإضافات المحملة والنطاقات التي تدعمها وحالة مزوديها. يمكن استدعاؤه من المتصفح مباشرة؛ CORS مفعّل للواجهة العامة.

{ "ok": true, "plugins": [{ "name": "youtube", "domains": ["youtube.com"], "status": "loaded", "providerStatus": { "youtubei": { "status": "closed", "failuresInWindow": 0 } } }], "requestId": "a1b2c3d4e5f6a7b8" }

POST/api/probe

يتعرف على الإضافة المناسبة ويعيد خيارات الجودة. يجب أن تكون الترويسة Content-Type: application/json.

curl -sS -X POST "https://YOUR-SERVICE/api/probe" \ -H "Content-Type: application/json" \ -d '{"url":"https://youtu.be/dQw4w9WgXcQ"}'
{ "ok": true, "title": "اسم الوسيط", "plugin": "youtube", "options": [ { "key": "v_720", "label": "720p", "kind": "video", "sizeHint": 0 }, { "key": "a_128", "label": "128kbps", "kind": "audio", "sizeHint": 0 } ], "requestId": "a1b2c3d4e5f6a7b8" }

POST/api/download

ينزّل الوسيط ويعيده في response stream. يعتمد key على نتيجة /api/probe.

curl -L -X POST "https://YOUR-SERVICE/api/download" \ -H "Content-Type: application/json" \ -d '{"url":"https://youtu.be/dQw4w9WgXcQ","key":"v_720"}' \ --output media.mp4

الترويسات المفيدة: Content-Disposition، Content-Length، X-Media-Title، X-Media-Type، X-Plugin وX-Request-Id.

رموز الحالة وإعادة المحاولة

الرمزالمعنىسلوك العميل المقترح
200نجاحاستخدم الاستجابة أو احفظ stream.
400 / 415رابط أو JSON أو Content-Type غير صالحصحح الطلب؛ لا تعِد الإرسال نفسه.
404 / 422جودة غير موجودة أو رابط غير مدعومأعد الفحص أو اعرض رسالة مناسبة للمستخدم.
429تجاوز حد الطلباتانتظر قيمة Retry-After ثم أعد المحاولة.
502 / 504المزود الخارجي أخفق أو تأخرأعد المحاولة لاحقاً بعد تأخير متزايد.

مثال JavaScript

const base = "https://YOUR-SERVICE"; const probe = await fetch(`${base}/api/probe`, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ url }), }).then((r) => r.json()); if (!probe.ok) throw new Error(probe.error); const key = probe.options[0].key; const media = await fetch(`${base}/api/download`, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ url, key }), }); if (!media.ok) throw new Error((await media.json()).error); const blob = await media.blob();
